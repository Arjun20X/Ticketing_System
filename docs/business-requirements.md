# Project Overview

What problem does this software solve?
    
This software resolves the complexity of complainig and resolving issue of customers to an employee in a hardware shop on time.

# Current Workflow

How complaints are handled today.

In present complaints are handled on call. Employees take calls , write the complain on notebook and then resolve them manually.
If the complain get lost there is no accountability also this way it takes a lot of time to resolve issues.

# MVP Scope

What is included?

In the first MVP the customers will be able to raise complaints using the chat ui , ai will ask follow up questions to complete all the required information,summarize the complain , categorize it, classify it and than the system will generate a ticket and store it on DB.

What is NOT included?

Dashboard
Analytics
Ticket assignemnt to agents
